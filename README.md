USB-C to Fast Ethernet Bridge v2
USB-to-Ethernet adapter designed in Altium with instant plug-and-play wired internet without requiring custom firmware or drivers.

Controller: Realtek RTL8152B-VB-CG  – 10/100M Ethernet Controller.
RJ45 MagJack with integrated isolation transformers and status LEDs.
Power: 100% bus-powered via AP2112K-3.3V LDO stepping down the smartphone's +5V VBUS.
